# low-context-writing

AIが書いた文章の「端折りすぎ」を、前提知識のない読者の目線で直す Claude のスキルです。

AIに書かせた文章は、整って見えても、読み手が多くの前提知識を持っていることを当てにした「ハイコンテキスト」な文章になりがちです。このスキルは Claude に一般書の校正者の視点を持たせ、「前提知識のない読者が、前を読み返さずに意味をたどれるか」という基準で文章を点検させます。説明のない専門用語、省かれた理由、出どころの分からない引用、因果関係を隠してしまっている箇条書きなどを見つけ、書き手の主張や文体は変えずに補います。

## 直す前と直した後の例

> 前：機械学習のホールドアウトセットと同じ考え方である。

> 後：機械学習では、データの一部を学習に使わずに取っておき、最後の評価にだけ使う。これを「ホールドアウトセット」と呼ぶ。学習で見たデータで評価すると、答えを丸暗記しただけでも高得点になってしまうからだ。

点検する11の観点と手順は [`low-context-writing/SKILL.md`](low-context-writing/SKILL.md) に書いてあります。

## 導入手順

### claude.ai（Web・アプリ版の Claude）で使う場合

1. このリポジトリの `low-context-writing.zip` をダウンロードする
2. claude.ai の設定を開き、スキルの画面から zip をアップロードする
3. スキルが有効になっていることを確かめる

### Claude Code で使う場合

どのプロジェクトでも使いたいなら、ホームディレクトリに置きます。

```bash
git clone https://github.com/high-tech-r/low-context-writing.git
mkdir -p ~/.claude/skills
cp -r low-context-writing/low-context-writing ~/.claude/skills/
```

特定のプロジェクトだけで使いたいなら、そのプロジェクトの `.claude/skills/` の下に `low-context-writing` フォルダを置きます。リポジトリにコミットすれば、チームの全員が同じスキルを使えます。

## 使い方

文章を渡して「読者目線で校正して」「前提知識なしで読めるか見て」などと頼むだけで、Claude がスキルを読み込んで点検します。確実に使わせたいときは `/low-context-writing` で呼び出してください。

修正案は「元の表現 → 修正案（理由）」の形で1か所ずつ出てくるので、納得できるものだけを取り入れてください。
